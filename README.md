## Spring Application for StoresManagement

### Features:
- **Products**
- **Warehouses**
- **Inventories**
- **Suppliers**
- **Customers**
- **Orders**

### Exposes web services to:
- Read and write data stored in MySQL database

### Access Configuration:
- External clients must target the **IP address** of the network router and **port 443**.
- External client connections require a routing configuration on the network router to route their calls to **ip_app_server:443**.
